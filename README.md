# HealthBig – Healthcare Big Data Analytics and Patient Risk Prediction System

Academic Big Data Analytics (BDA) mini-project focused on healthcare analytics, patient risk prediction, chronic disease profiling, and simulated real-time vital telemetry.

Please refer to [`healthbig/README.md`](./healthbig/README.md) for the complete documentation, architectural diagrams, REST API specs, and ML pipeline details.

## Quick Launch:
- Double click `run_all.bat` to start both the FastAPI backend (port 8000) and the Vite React frontend (port 5173).
- Or run `run_backend.bat` in one terminal and `run_frontend.bat` in another.
